# Shahin Ghanbari

I use Python to study dietary data, build prediction models, and evaluate what happens when model scores are turned into decisions.

## Featured research

### Diet-only health prediction with NHANES

This project uses 24-hour dietary recalls to explore prediction of hypertension, diabetes, and thyroid dysfunction. The notebook trains a multi-label deep learning ensemble, calibrates its probabilities, and measures how different thresholds affect precision, recall, and alerts per 1,000 people screened. [Research notebook and project guide](https://github.com/Shahin-Ghanbari/Diet-Only-Multi-Label-Prediction-Using-a-Calibrated-Deep-Learning-Ensemble)
